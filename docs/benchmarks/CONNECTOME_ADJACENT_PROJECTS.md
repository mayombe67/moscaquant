# Connectome-Adjacent Project Register

This register tracks external projects that can improve MoscaQuant engineering, validation, or comparative framing. It is not a feature-shopping list.

## Current classifications — 2026-09-19

### Provenance / reproducibility patterns — ADOPT

Adopt explicit empirical/surrogate/synthetic classification, SHA-256 artifact hashes, runtime-profile provenance, executable pass/fail acceptance, and fail-closed migration checks.

### soup-connectome — BENCHMARK

Useful for backend portability, parity tests, explicit device planning, and deterministic runtime contracts. Do not adopt its fixed-point LIF semantics as MoscaQuant scientific dynamics without a separately justified scientific change.

### FlyDrones / Closed-Loop Fly — INSPECT ADAPTER BOUNDARIES

Useful for sensory interfaces, visual-encoding plumbing, descending-neuron inspection, and separation of neural state from engineered world/action mappings. Do not inherit their motor/control semantics into MoscaQuant trading.

### flyquant — TRACK AS ADJACENT TRADING COMPARATOR

Compare methodology instead of copying execution design: precommitment, null/control families, reproducible artifacts, causal perturbation evidence, held-out financial validation, separation of biological evidence from engineered market semantics, and independent WARDEN-01 financial containment.

## Project objective boundary

Financial performance is downstream of the experiment.

A profitable account would be interesting. It would not retroactively validate the neuroscience. An unprofitable account would not erase a valid scientific result.

MoscaQuant's initial purpose is the experiment: make the connectome do something absurd, then test the absurdity honestly.
