# ADR-0005: MQ-001 Embodiment

**Status:** Accepted

MQ-001 will eventually inhabit a virtual fly body inside a 3D containment chamber and trading workstation.

The environment intentionally uses a PS1/PS2-era containment-simulator aesthetic while Neuroscope retains detailed scientific connectome visualization.

Where biologically meaningful mappings exist, body behavior should derive from actual neural and motor telemetry rather than canned trade animations.

The Containment Chamber and Neuroscope are two observable views of the same experimental subject.
