# ADR-0003: Oracle D6 Protocol

**Status:** Accepted

The Oracle provides experimental behavioral correction after designated loss events.

Canonical outcomes:

1. The Shock
2. Darkness
3. Bad Synapse
4. Time Out
5. Scar Tissue
6. Mercy

The roll must be unbiased. Oracle interventions may affect MQ-001 but can never modify Warden policy or reopen trading after Sugar Cube Mode activates.
