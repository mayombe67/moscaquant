# SQ-03A — THE OTHER FLY

## Matched Central-Brain Comparative Protocol

**Status:** FROZEN BEFORE NEURAL EXECUTION  
**Class:** Scientific side quest / biological comparator qualification  
**Subjects:** MQ-001 // MORTY and MQ-002 // LILITH

## Question

When the same standardized stimulation is applied to the same officially
cross-matched central-brain input labels, do the male and female aligned
connectome weight sets produce different deterministic responses at
pre-existing MoscaQuant descending-neuron anchors?

## Why the scope begins inside the central brain

MQ-002 qualification established that MoscaQuant's frozen artificial retinal
and optic-lobe relay labels are not present in the official MaleCNS/FlyWire
aligned central-brain edge comparison.

The corrected causal-source audit also established that the previously frozen
MQ-5 optic-lobe source neurons do not occur in that aligned comparison, while
the corresponding downstream descending-neuron targets do.

SQ-03A therefore does not infer, synthesize, or reconstruct a female optic-lobe
pathway.

The experiment begins at a preregistered matched central-brain input panel and
uses frozen downstream anchors derived from existing MoscaQuant experiments.

## Frozen comparison graph

Use only rows from the official MaleCNS/FlyWire aligned-edge product satisfying:

- `verdict_corr == "isomorphic"`
- `weight_m > 0`
- `weight_f > 0`

The male and female simulations use the same node identities and edge set.

The only connectomic difference is the published aligned edge weight:

- MORTY: `weight_m`
- LILITH: `weight_f`

No missing edge may be inferred.
No shuffled edge may be inserted.
VNC anatomy remains excluded.

The output anchors are fixed before execution from pre-existing MoscaQuant
downstream targets:

MQ-001 model-index numbering in MQ-002.

## Stimulus

Each frozen input label is stimulated separately with the same standardized
pulse schedule and amplitude in both subjects.

The pulse has no BUY / HOLD / SELL meaning and carries no market or financial
semantics.

The exact numerical amplitude, duration, timestep, membrane parameters, and
initialization behavior must be inherited from one existing validated
MoscaQuant runtime profile or frozen in an implementation config before the
first result-bearing execution.

They may not be tuned separately for MORTY and LILITH.

## Primary outputs

For every input-label / anchor combination record:

- voltage trace;
- first-positive frame;
- peak voltage;
- integrated positive voltage.

Also record deterministic replicate agreement.

## Comparative summaries

Predefined summaries are:

- per-input, per-anchor MORTY-minus-LILITH response delta;
- aggregate response-vector distance;
- anchor rank-order stability;
- deterministic replicate agreement.

A difference is a model result. It is not automatically a biological mechanism.

## Controls

Required controls:

1. deterministic A/A replay for MORTY;
2. deterministic A/A replay for LILITH;
3. identical stimulus schedule across subjects;
4. identical non-connectomic runtime parameters;
5. identical node identities and edge inclusion rule.

SHUFFLED MOSCA remains a separate randomized-topology control family and is not
replaced by MQ-002.

## Stop conditions

Stop and report qualification failure rather than modifying the protocol if:

- any frozen input label is absent from either subject's matched edge set;
- any frozen anchor cannot be represented under the official cross-match;
- runtime parameters differ between subjects for reasons other than aligned
  edge weights;
- implementation requires inferred anatomy;
- implementation requires reconstructing the unavailable female optic-lobe
  pathway.

## Claim boundary

SQ-03A compares deterministic responses of independently derived, officially
cross-matched Drosophila connectome weight sets inside a preregistered
central-brain subgraph.

It does not establish:

- sex superiority;
- intelligence differences;
- general behavioral differences;
- a biological mechanism without additional evidence;
- market skill;
- profitability;
- financial usefulness.

No financial authority, broker authority, WARDEN authority, or ORACLE authority
is assigned by this protocol.
