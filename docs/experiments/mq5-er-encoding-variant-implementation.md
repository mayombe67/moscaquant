# MQ-5.ER Encoding-Variant Implementation

Status:

**IMPLEMENTATION / ENCODING-ONLY VERIFICATION**

No neural result is generated by this implementation step.

## Purpose

Implement the preregistered MQ-5.ER encoding variants behind a dedicated
encoding-only interface while leaving the accepted frozen
`MarketVisionTemporalEncoder` unchanged.

## Design

`brain/mq5_er_encoder.py` subclasses the frozen temporal encoder but does not
modify its source.

The variant interface supports:

- Arm A — frozen encoder behavior;
- Arm B — fixed `2.5` cadence;
- Arm C — zero entropy-jitter contribution;
- Arm D — balanced asset/ticker-to-territory permutations;
- Arm E — no momentum-dependent temporal motion.

## Arm A identity requirement

Arm A delegates the temporal gate to the frozen parent implementation and
retains the original motion calculation.

The software contract requires byte-identical output against the frozen encoder
for the same spatial encoder state, feature matrix, and frame count.

This is tested before any connectome-level use.

## Arm B

Only cadence selection changes.

The frozen feature matrix is not edited.

The cadence is fixed at:

`2.5 cycles / observation`

Entropy jitter and momentum motion remain active.

## Arm C

Only the entropy phase-jitter contribution changes.

The normalized entropy feature is not replaced or edited.

The phase-jitter multiplier is fixed at:

`0.0`

Volatility-derived cadence and momentum motion remain active.

## Arm D

Arm D permutes complete six-feature rows before spatial/temporal encoding.

Each row remains a seven-feature vector.

The implementation reproduces the existing balanced mapping construction:

- six rotations of identity;
- six rotations of reversed identity;
- twelve total mappings;
- each asset appears in each territory exactly twice.

No outcome-dependent mapping selection is implemented.

## Arm E

Only momentum-dependent temporal motion is removed.

The effective motion weight becomes:

`1.0`

The normalized momentum feature remains unchanged.

Spatial encoding, cadence, entropy jitter, and energy normalization remain
active.

## Fairness invariant

Every arm preserves mean integrated energy of each retinal territory across the
encoded observation window.

The implementation does not contain or call a neural runtime.
