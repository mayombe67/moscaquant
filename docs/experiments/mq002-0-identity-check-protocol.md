# MQ-002.0 — IDENTITY CHECK // LILITH

## Published Male/Female Mapping Qualification Protocol

**Status:** FROZEN BEFORE DISCOVERY  
**Class:** Non-result-bearing data qualification / feasibility study  
**Parent program:** MQ-002 // LILITH — THE OTHER FLY

## Question

Do the official MaleCNS/FlyWire cross-matching products provide enough
traceable overlap with the frozen MQ-001 scientific interface to justify
designing a matched biological-topology experiment?

## External source products

The qualification targets the official Berg et al. MaleCNS companion products:

- `mcns_fw_edge_comp_mappings.json`
- `mcns_fw_edge_comp.feather`

The mapping JSON is small enough to acquire during discovery.

The ~96 MB aligned-edge Feather file is NOT downloaded automatically in this
first pass. Discovery records its expected role and only recommends acquisition
after local overlap has been characterized.

## Read-only discovery measurements

Record:

- repository HEAD and clean/dirty status;
- provenance URL used for the official mapping JSON;
- SHA-256 of the acquired mapping JSON;
- mapping entry count;
- number of unique cross-matched labels;
- available local MaleCNS identity/index artifacts;
- overlap between published mapped MaleCNS body IDs and any locally
  discoverable body-ID sets;
- overlap with retinal, relay, responder, descending-neuron, or other frozen
  interface artifacts when body IDs are locally available;
- missing/unresolvable interfaces;
- whether the aligned-edge Feather file is already present locally.

## Interpretation

This step produces no neural, behavioral, biological-sex, or financial result.

A large overlap does not prove comparability.

A small overlap does not prove that the program is impossible.

The output is used only to design a later protocol. Any inclusion threshold,
matched-subgraph definition, female edge construction, or result-bearing
comparison must be frozen separately before execution.

## Prohibited shortcuts

Do not:

- treat unmatched VNC anatomy as female-matched anatomy;
- manufacture female edges from MaleCNS weights;
- replace missing female structure with SHUFFLED MOSCA;
- infer neuron equivalence from names alone when the official mappings disagree;
- run a male/female neural comparison from this discovery script;
- change the frozen MQ-001 runtime.

## Claim boundary

MQ-002.0 establishes only the availability and local coverage of published
cross-matching data needed to design a future comparative experiment.
