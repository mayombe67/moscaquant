Neuroscope Science Dashboard Guide

Neuroscope is MoscaQuant's read-only visualization, replay, and scientific inspection layer. It combines hybrid MaleCNS geometry, frozen replay telemetry, preserved causal-path evidence, graph traversal, responder analysis, and MQ-5 intervention replay from completed experimental artifacts.

Color Cheat Sheet

BLUE — real soma geometry
GRAY — topology fallback
ORANGE — causal responder / causal overlay
WHITE — spike or selection emphasis
CYAN — effective activity / upstream trace
GREEN — downstream trace

Geometry

Real soma geometry

Nodes marked somaLocation use real MaleCNS soma coordinates. These are anatomical data.

Topology fallback

Nodes marked topologyFallback lack usable soma geometry in the frozen Neuroscope geometry artifact. Their displayed positions preserve useful topology only.

Topology fallback coordinates are not anatomical coordinates and must not be interpreted as anatomical evidence.

Display Controls

  • Real soma geometry — show/hide real anatomical soma positions.
  • Topology fallback — show/hide non-anatomical fallback placement.
  • Causal overlay — show/hide the frozen MQ-3.2 causal graph.
  • Responders only — restrict display to responder neurons.

Replay

Neuroscope contains 192 recorded replay frames, numbered 0 through 191.

  • Previous frame
  • Play / Pause
  • Next frame
  • 2, 4, 8, 12, or 24 fps playback
  • Direct timeline scrubbing

Manual timeline movement automatically pauses playback.

Frame summary

  • Retinal spikes
  • Relay spikes
  • Graded-active count
  • DN mean activity
  • DN maximum activity
  • DN spikes
  • Maximum responder value
Replay is recorded telemetry. Pressing Play does not execute a new simulation.

Activity Visualization

  • Voltage magnitude increases node brightness and size.
  • Effective activity receives cyan emphasis.
  • Spikes receive bright white emphasis.
  • Responders remain amber regardless of momentary activity.
  • Responder magnitude can increase responder size.

MQ-5 Intervention Replay

The INTERVENTION REPLAY panel exposes completed MQ-5 intervention evidence inside Neuroscope.

It reads the frozen downstream artifact mq5-interventions-v1.json. Neuroscope does not execute the intervention runtime and does not generate new experimental outcomes.

Generalized single-edge replay

The generalized family exposes all 13 frozen causal edges and the recorded 25%, 50%, 75%, and 100% attenuation conditions.

Where available, the dashboard also displays the frozen timing and matched-control evidence. A missing control remains unavailable; the viewer does not construct a replacement.

Two-hop pathway replay

56393 → 68045 → 1273 upstream causal frame F146 intermediate causal frame F147

The pathway view can compare completed upstream and intermediate perturbations against their recorded baseline traces.

Convergence replay

Neuroscope exposes the three frozen convergence systems:

44274 + 55925 → 55 55548 + 87441 → 51 92657 + 93484 → 129

A-only, B-only, and combined conditions are descriptive replays of completed MQ-5 results.

Combined effect greater than either single input is not, by itself, a statistical synergy claim. Neuroscope does not assign synergy, antagonism, subadditivity, or superadditivity.
Responder 51 effects occur at an extremely small numerical scale. Their magnitude must be interpreted cautiously.

Robustness and provenance

Provenance indicators may report completed CONF-004A normalization robustness and MQ-5.6 independent-runtime replication evidence. These are existing experimental results, not evidence generated by the dashboard.

Trace interpretation

  • Baseline traces are frozen recorded telemetry.
  • Intervention traces are frozen recorded telemetry.
  • Dose selection changes which completed result is displayed.
  • Jumping to a causal frame changes viewer position only.
  • Missing telemetry is displayed as unavailable rather than reconstructed.
INTERVENTION REPLAY IS READ-ONLY. IT DOES NOT RUN MOSCAQUANT.

Scientific Boundaries

Neuroscope is a read-only interpretation layer over frozen MoscaQuant experimental telemetry.
  • No synthetic fallback is promoted to anatomy.
  • Replay does not rerun the experiment.
  • Intervention Replay does not execute interventions.
  • Traversal does not create new causal edges.
  • Visualization does not strengthen the underlying evidence.
  • Responder magnitude does not establish causal importance.
  • Filtering never changes the underlying dataset.
  • Biological causality is not claimed.

Troubleshooting

source .venv/bin/activate python -m neuroscope.build_web_replay

Hard-refresh the browser or add a cache-busting query parameter:

http://127.0.0.1:8080/?fresh=1

Check JavaScript

node --check neuroscope/web/app.js git diff --check

Check what the web server is serving

curl -s http://127.0.0.1:8080/app.js | grep -n "RESPONDER ENSEMBLE"

Principle

Visualization may make the evidence easier to understand, but it must not silently change what the evidence means.
